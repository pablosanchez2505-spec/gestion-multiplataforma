src/app/features/items/item-name-unique.validator.ts

itemNameUniqueValidator
itemNameUniqueValidator(api: ApiService, debounceMs: number)

Validador ASÍNCRONO: el nombre del producto no puede estar repetido.

  • Un validador síncrono responde al instante; este tiene que preguntar al servidor, así que devuelve un Observable. Mientras espera, el control queda en estado pending.
  • timer(debounceMs) + switchMap = debounce: si el usuario sigue escribiendo, la comprobación anterior se cancela y solo se hace la última (una petición por pausa, no por tecla).
  • Si el servidor falla, catchError deja pasar el valor: el servidor volverá a comprobarlo al guardar, y el formulario no se queda bloqueado.
Parameters :
Name Type Optional Default value
api ApiService No
debounceMs number No 400
Returns : AsyncValidatorFn
